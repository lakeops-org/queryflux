QueryFlux × OPA (Keycloak OIDC)

Iceberg tables in Lakekeeper (lakekeeper.demo.customers / payroll) seeded by Compose. Identity comes from Keycloak — "Run query" fetches a real OIDC token for the selected user via a password grant and sends it as Authorization: Bearer …, same as demo.py. QueryFlux resolves schema from the catalog for OPA masks and filters. Dry-run and Ask OPA still take identity directly (no token needed — they don't go through the authenticated query path). Policy: access.rego

Start Compose + docker compose --profile seed run --rm data-seed, then QueryFlux on :8080. Seed reloads seed.sql rows. "Run query" and "Seed data" fetch a Keycloak token for the selected identity's password first.
